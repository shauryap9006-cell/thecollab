# thecollab

**Your Website. Your Brand. Your Reach.**

thecollab is a digital growth agency that helps businesses build a stronger online presence through high-quality websites, social media content, and creator-led marketing campaigns.

This is our 3D interactive website — a scroll-driven Three.js experience built by thecollab, for thecollab.

## Tech Stack

- Next.js (static export)
- React Three Fiber + drei
- GSAP
- Zustand
- Tailwind CSS
- Three.js

## Development

```bash
npm install
npm run dev
```

## Deployment

Deploys to GitHub Pages on push to `master` via `.github/workflows/deploy.yml` (static export under the `/thecollab` basePath).

## Business info

All contact details (WhatsApp, email, Instagram) live in `app/constants/site.ts` — update them there.
